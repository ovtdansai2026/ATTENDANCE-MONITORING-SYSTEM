# ระบบติดตามการเข้าแถวและกิจกรรมกลาง v2.0
**วิทยาลัยการอาชีพด่านซ้าย (Dan Sai Industrial and Community Education College)**

ระบบแดชบอร์ดติดตามการเข้าแถวหน้าเสาธงและการเข้าร่วมกิจกรรมกลางของนักเรียน-นักศึกษา แบบ Single-File Modern React Architecture พัฒนาขึ้นเพื่อการติดตามผลอย่างแม่นยำ รวดเร็ว และโปร่งใส

---

## 🌟 จุดเด่นของระบบ
- **Modern Single-File Web App:** ใช้งานง่าย ไม่ต้องติดตั้งโปรแกรมหรือมีขั้นตอน Build ที่ซับซ้อน
- **Real-Time Data Sync:** เชื่อมต่อฐานข้อมูล Supabase แบบ Direct REST API
- **Dynamic Term Management:** รองรับการจัดการปีการศึกษาและภาคเรียน ปฏิทินวันเรียน วันหยุด และวันชดเชย
- **80% Remediation Criteria:** วิเคราะห์และตรวจสอบเกณฑ์การเข้าแถว 80% แยกตามรายคนและรายแผนกวิชา
- **Teacher Check-in & Evidence:** ระบบบันทึกการเช็คชื่อของครูที่ปรึกษาพร้อมภาพถ่ายหลักฐาน
- **Mobile Responsive:** รองรับการแสดงผลทั้งบนโทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์

---
